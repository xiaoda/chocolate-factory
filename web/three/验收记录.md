# 涂层机互动工序样板 V0.2 验收记录

日期：2026-10-08。范围：开发方案第二批任务 4–6，以及本批必要的故障回退、资源与页面回归。V0.1 造型与 V0.2 动画效果均已获用户认可，用户已授权本批本地提交；尚未扩展其他设备。效果认可不替代工业工艺验证。

## 本批实现

- 75 秒教学时间轴：认识输入、淋涂/底涂、控量回收、独立冷却、输出对照。默认不播放，结束不循环。
- 三块错位芯体沿网带移动，主产品用金色圆环跟踪；包覆使用独立顶层、侧层和底层几何，不只是换色。
- 同步“进入 / 动作 / 得到”说明、阶段注意事项和正文步骤链接。蓝色冷却段、回流路径始终有示意边界。
- 播放/暂停、重播、进度拖动、阶段关键帧、上/下一步、工作部件/完整外观；保留旋转、缩放、部件高亮与实拍对照。
- 同一时刻的状态由纯函数求值；隐藏/离屏保留播放意图但挂起时间，用户暂停不会被自动取消。
- 按部件及材质合并静态几何，保留独立外壳与动态网带；解决窄屏标签重叠及 320 像素播放工具换行。

## 性能与资源

环境：Windows、Intel Core i7-11800H；HeadlessChrome 154；浏览器报告 16 个逻辑核，ANGLE / Intel UHD Graphics / D3D11。桌面视口 1440×1100，像素比 1。

- 优化前控量阶段约 263 次绘制；静态几何合批后，37 秒控量帧约 139 次绘制、65,002 个三角形。
- 连续运行 300 秒，每秒采样，共 300 条，测试脚本主动重播 3 次，覆盖全部五阶段；未出现临时挂起。每秒帧数的中位数约 60.14、低 5% 分位约 59.28、均值约 58.67（包含播放结束等待测试脚本重播的停顿）。这是本机无头浏览器观测，不是所有设备的性能保证。
- 采样期间绘制调用 76–139，最多 65,002 个三角形；渲染器几何计数始终为 73、纹理计数始终为 3，未随重播增加。测试脚本结束时主动暂停；正式功能仍不自动循环。
- 生产文件：主块 606,784 字节、CSS 15,379 字节、轻入口 3,339 字节、许可 1,187 字节，总计 626,689 字节。未将 gzip 估算混作实际 HTTP 传输。
- 浏览器 Resource Timing 报告主块 encodedBodySize 为 606,784、transferSize 为 607,084 字节；本地服务未压缩主块。
- Vite 的单块超过 500 KB 提示仍为已知构建告警；总量低于 3 MB 预算且重模块按需加载。
- 尚未测真实手机 FPS、温升、GPU 显存或长时 JS 堆快照；渲染器计数稳定不等同于证明不存在任何内存泄漏。
