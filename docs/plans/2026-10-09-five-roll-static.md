# V0.6：五辊精磨机静态样板实施计划

> 使用 brainstorming / architecture-designer 明确边界，writing-plans 编写，executing-plans 分步实施。用户已确认开发；本批不自动提交，不派子代理。

**目标：** 参照照片 19／20 制作可旋转、观察部件和实拍对照的五辊精磨机静态样板；在基础巧克力页与石磨机切换。

**架构：** 复用现有 SceneDefinition / MachineInstance、按需查看器和程序化几何；新增五辊静态数据与懒加载场景。Python 生成多个独立设备区，前端根据片段 URL 只激活一台，切换先释放旧实例，再等待用户主动加载新实例。

**技术栈：** 现有 Python、TypeScript、three.js、Vite、Vitest / unittest；无 Blender、第三方模型或新增依赖。

## 照片依据与边界

- 已实际查看原始照片 19 与展牌 20。保留五根平行辊筒、左右浅色立架、底框、左上深色电机、侧罩、右侧仪表旋钮和左侧小面板。
- 辊径、前后错位、尺寸和背面均为造型简化，不代表测量结果；蓝色光纹不用于推定物料流向，模型不复刻该光效。
- 展牌作为用途和辨识依据；本版没有转动、辊间传料、进出料口或操作模拟。典型输入/结果是文字说明，不把精磨等同精炼，不复刻生产参数。
- 只关联正文第 4 步 `混合 · 五辊精磨`，不把石磨输出直接画成已配料的五辊输入。
- 默认完整外观；“辊组观察”仅隐藏局部上部横挡与外侧罩，帮助观察，不能解释为真实拆卸或内部剖面。

## ADR：同页多设备

备选：① 两查看器同时运行（浪费资源）；② 新增独立设备页（重复正文/新导航层级）；③ 同页设备区 + 独占实例（采用）。

- 保留石磨与涂层旧锚点 `#equipment-3d`；五辊使用 `chocolate.html#equipment-five-roll`。
- 设备区 ID、标题、进度输入 ID 均唯一。普通 HTML 链接支持深链接和浏览器前进/后退；无 JS 时两个设备区均可阅读实拍与边界。
- 有 JS 时隐藏非当前设备，点击普通正文锚点不强制切换；点击设备锚点才切换。默认石磨，直达五辊时不先加载石磨。
- 切换/离页即释放旧场景、监听器和帧循环；取消未完成加载，迟到的异步结果不得挂载；返回旧设备需重新加载，时间从零开始，不自动播放。
- 首页第三张卡标“静态样板 / 暂无动画”，不显示 0 秒或播放按钮。目录标题升级为“3D 设备与动画”，保留 `#animations` 旧链接。
- 风险：异步加载竞争、重复 ID、旧播放控件残留、同页导航焦点。用纯生命周期测试、HTML 契约和实际浏览器切换覆盖。
