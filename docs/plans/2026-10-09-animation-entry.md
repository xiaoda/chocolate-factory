# V0.5：3D 设备动画统一入口实施计划

> 使用 writing-plans 编写、executing-plans 分步执行；当前任务内实现，不派子代理。用户已确认首页专区、设备切换、工序入口三个方向；本批交付预览，不自动提交或推送。

**目标：** 让读者能从首页找到全部已完成动画，在设备页互相切换，并从对应正文工序返回演示。

**架构：** 静态 Python 生成入口；目录的时长、阶段、照片与正文映射复用现有场景数据。首页只展示两张实拍卡片，不加载 three.js；设备页沿用主动加载、主动播放。纯图文构建隐藏全部动画入口。

**技术栈：** 现有 Python 静态生成器、HTML/CSS、unittest；既有 TypeScript/Vitest 仅做回归。无新依赖、图片生成、上传或新模型。

## 设计决策

- 采用首页静态专区，而非新建独立展厅（目前只有两台设备，增加页面层级无必要），也不在首页内嵌双场景（增加加载与图形资源成本）。
- 沿用纸色、深绿与铜色的工艺手册风格。专区放在首页首屏介绍之后，使用设备分类、实拍、输入/结果对照、教学时长和阶段数；明确封面是设备实拍，不冒充动画截图。
- 全站主导航增加“3D 动画”；设备区顶部增加“全部动画 / 石磨机 / 涂层机”，当前项使用 `aria-current`；正文入口链接到当前页 `#equipment-3d`，不承诺自动加载、播放或跳转特定动画时间。
- 只在场景阶段实际关联的正文步骤提供入口。石磨对应第三步；涂层对应两路输入、淋涂、控量与冷却说明，保留输入准备与补充冷却不是本机加工功能的既有边界。
- 普通链接支持无 JavaScript 导航、键盘访问和浏览器返回；不新增交互状态管理。手机卡片改为单列，导航可换行而非隐藏链接；打印隐藏操作入口。
