# 巧克力工艺图解手册：设计说明

## 已确认的目标
用户选择「总览入口＋9 个独立单页」。利用参观实拍，把产品、设备、物料变化和制作顺序联系起来；能快速浏览，也能逐步阅读。

## 信息架构
总览 → 基础巧克力、金币巧克力、涂层巧克力、巧克力球、夹心巧克力、棒棒糖、方登糖基、切块糖果、奶片。
每页包含一句话原理、原料/成品、速览流程、分步解释、设备照片、易混淆点、自测、来源和相邻页面导航。
切块糖果只还原共同后段，不虚构各种产品共享的前端配方。夹心页明确区分模壳与涂层两条路线。

## 视觉与交互
采用博物馆工艺手册的编辑式版面：奶油纸色、深可可色、铜橙强调色；宋体标题、清晰的无衬线正文；大序号、细分隔线、设备照片和展牌附件。
核心信息不隐藏在交互后。总览可按类别筛选；步骤可锚点跳转；照片可放大并打开原图；扩展知识和来源可展开；支持打印。
手机改为单列，无横向滚动；键盘可操作，尊重减少动画设置。

## 证据边界
实拍照片、资料补全分开标注。不将照片编号当作生产顺序，不给未知机器强行命名。不把典型工艺写成该厂实际配置，不把展牌温度写成通用生产参数。
补充两张公共领域/CC0 资料图（可可果、金币成品），保留作者和来源。照片原件不改动。网页和图片均保存在本地，不上传公网。

## 实现与验收
纯静态 HTML/CSS/JS，Python 标准库生成重复页面；生成物无需 Python 即可阅读。预览服务仅监听 127.0.0.1，仅提供 web/dist，禁止目录列表；隐藏运行并记录日志、PID、实际端口。
Chrome DevTools 独立页面验证桌面/手机截图、链接、图片、控制台、筛选、照片放大与键盘关闭；自动检查全部本地引用和证据标注。
